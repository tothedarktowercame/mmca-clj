# Provenance for the Supplement 1 findings

One row per box in Supplement 1 of *Rule-Rewriting Cellular Automata and the
Edge of Chaos*, giving the command that regenerates its numbers.

The paper's single complete command is:

    scripts/reproduce_all.sh --full

It runs all twelve boxes in producer-before-consumer order. Without `--full`,
the command still regenerates boxes 2–5 and 7–12, but explicitly reports the
two long resumable enumerations (boxes 1 and 6) as skipped. It never silently
uses those committed results while claiming to have regenerated them.

All runs are seeded, so repeated runs of the same command give identical
numbers. Figure rendering requires the pinned plotting stack (`.venv`,
Matplotlib 3.11.1) — see the figure-pipeline note in `README.md`.

## Box 12 provenance

The committed published panel (commit `997f5f8`) is the seven-mechanism panel,
not the later exploratory dial-4 plot. Its exact chain is:

1. `full_population_sweep.clj` → `data/full_population_sweep.tsv`
2. `mutation_axis.clj` → `data/mutation_axis.tsv`
3. `diversity_dial2.clj` → raw TSV → `data/diversity_dial2_summary.tsv`
4. `diversity_dial3.clj` → raw TSV → `data/diversity_dial3_summary.tsv`
5. `assemble_diversity_axis.py` → `data/diversity_axis.tsv`
6. `plot_published_diversity_axis.py` → the published three-panel figure

`scripts/reproduce_diversity_axis.sh` is the single entry point for that exact
chain. The dial summaries are generated by
`summarize_reproduction_data.py`; they are no longer undocumented shell
reductions.

## Runtime and the determinism check

Measured on 2026-07-28: **52 minutes** for a full `reproduce_all.sh` from an
empty `data/` (a second, cache-warm run took 30 minutes). `--full` adds the 8!
permutation census and the offset+1 finite-size scan and takes substantially
longer; budget hours, not minutes.

The claim that repeated runs give identical numbers is checked, not assumed.
`scripts/verify_determinism.sh` runs the pipeline twice from an empty `data/`
and compares a SHA-256 of every generated artifact. Result of that run: both
passes exited 0 and **all 307 artifacts were byte-identical**; the only
difference in stdout across the two runs was the reported wall time.

The regenerated artifacts were also compared against the published ones on
disk: of the 298 files present in both, **all 298 matched**. So the numbers in
the paper are the numbers this pipeline produces, not merely numbers it
reproduces consistently.
